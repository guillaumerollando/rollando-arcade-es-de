# Rollando Arcade for ES-DE

A clean, console-like theme for [ES-DE](https://es-de.org): a column of system logos over full-screen artwork,
and game lists built around big game logos, descriptions and trailers.

*Screenshots coming soon.*

## Features

- **System view**: a column of system logos on the left, the system artwork full screen behind it.
- **Game lists** (pick one in *UI Settings → Theme variant*):
  - **Covers** (default) – flat, uncropped box art;
  - **3D boxes** – 3D box art;
  - **Physical media** – discs, cartridges and UMDs;
  - **Logos + cover** – a column of game logos, the cover next to it;
  - **Logos + 3D box + media** – a column of game logos, the 3D box and the disc / cartridge next to it.
- **No looping game lists**: lists have a start and an end. Use **LB / RB** to switch systems.
- **"System › Game" header**, game logo, genre, players / play time / play count, rating, description panel,
  and the trailer (or a screenshot) bottom right.
- **Options**
  - *Theme color scheme*: media on the right (video / screenshot / none) × background darkening (light / normal / dark);
  - *Theme font size*: medium / large / x-large;
  - *Aspect ratios*: 16:9 and 16:10 (Steam Deck).
- English and French labels; other ES-DE languages fall back to English.
- 194 of ES-DE's 195 systems have artwork and a logo.
- Steam games have no 3D box or physical media: flat covers are used for them.

## Installation

Download the theme (green *Code* button → *Download ZIP*), extract it into ES-DE's theme folder
(`~/ES-DE/themes/` on Linux and macOS, `ES-DE\themes\` on Windows) and select **Rollando Arcade** in
*UI Settings → Theme*. Scrape your games with ES-DE's scraper to get covers, logos, 3D boxes,
physical media and videos.

## En français

Thème ES-DE épuré, façon console : une colonne de logos de consoles sur une illustration plein écran,
et des listes de jeux centrées sur le logo du jeu, sa description et sa bande-annonce.
Les intitulés des options sont traduits en français. Variantes : jaquettes (par défaut), boîtes 3D,
supports (CD, cartouches), logos + jaquette, logos + boîte 3D + support. Les listes de jeux ne bouclent pas : LB / RB pour changer de console.
